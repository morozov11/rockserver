RockServer — что это, по-пацански

Коротко и без воды: зачем сервис, что уже умеет, чего ещё нет.

Человек говорит: «спокойный инструментальный джаз».
RockServer отвечает: вот станции, вот ссылки на потоки, вот кто выше в списке.
СЕЙЧАС — уже работает СКОРО — следующий этап ПОТОМ — дальше по плану

1. Суть в одном абзаце

RockServer — это бэкенд поиска интернет-радио для Windows-клиента RockCast. Клиент крутит звук. Сервер только ищет станции и отдаёт нормальный ранжированный список. Если сервер ляжет — у RockCast остаётся свой локальный каталог. Тут сервер и клиент не мешают друг другу.

2. Кто что делает

ПОТОМ

RockCast

Клиент. Пока с этим сервером ещё не склеен. Воспроизведение живёт там, не здесь.

СЕЙЧАС

RockServer

Rust/Axum. Принимает текст, валидирует, ищет по метаданным, отдаёт список с score.

3. Как идёт поиск сейчас

Нейросеть пока не участвует. Сейчас это честный детерминированный матч по названию, тегам, языку, стране.

СЕЙЧАСPOST /v1/search«calm jazz» + locale + limit
СЕЙЧАСПроверка входабитый JSON → 400, кривая схема → 422
СЕЙЧАСНормализациятермы, теги, язык/страна
СЕЙЧАСФильтр + scoreвыше score выше; ничья → по id
СЕЙЧАСОтветстанции, URL потока, reason
Важно: запрос поиска не ходит в Radio Browser и не долбит потоки. Каталог либо уже в Postgres, либо это встроенные 6 станций.

4. Откуда берётся каталог

  • Есть Postgres → сервис ищет в нём.
  • Нет DATABASE_URL → крутит шесть встроенных станций в памяти.
  • Импорт Radio Browser — отдельная команда, только в Postgres, с потолком страниц.
  • Повторный импорт обновляет «свои» станции, чужие builtin не затирает, пропавшие upstream сам не удаляет.

6. Что уже есть / чего нет

Уже в деле

  • GET /health/live — процесс жив
  • GET /health/ready — для Postgres ещё и БД отвечает
  • POST /v1/search — поиск по метаданным
  • OpenAPI контракт
  • Миграции + seed + импорт Radio Browser

Пока не трогаем

  • Умный semantic ranking
  • LLM в продакшене
  • Авторизация / rate limit
  • Проверка живых потоков
  • Интеграция с RockCast и голос

7. Итог

RockServer — это поисковик радиостанций для RockCast.
Сейчас он честно ищет по каталогу и отдаёт ранжированный список.
Потом научится понимать запрос умнее. Крутить музыку он не будет — это работа клиента.
Локальный файл, без сети и внешних скриптов. Состояние на RS-006 (импорт Radio Browser есть, semantic ещё нет). Технические схемы лежат отдельно в docs/service-diagrams.html — этот файл их не заменяет.
