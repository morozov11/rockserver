# RM-004-G — offline release synchronization

The shared baseline is adopted only with the explicit offline command in
`C:\repos\rockcast-station-catalog\tools\release_sync.py`. Select an immutable
`release/<catalogVersion>` directory, use `--dry-run`, apply the copy, review the diff, then run
`verify`. It validates schema/version/manifest/SHA-256 and rejects drift or corruption. Cargo and
startup never invoke this command or fetch a catalog.

Rollback pins a prior immutable release with the same command; provider-owned rows and legacy data
are not deleted. An emergency stream replacement is a reviewed later canonical release, never an
in-place artifact edit. RockCast's TXT adapter is outside RockServer and remains only for its
documented one-transition-cycle period.
