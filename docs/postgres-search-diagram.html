1. HTTP-запрос → SearchService

POST /v1/search или POST /api/v1/voice/command

Принимает: query, locale, limit, exclude_stations

2. Интерпретация запроса (QueryParser)

LLM-парсер (Yandex) или детерминированный fallback.
Провайдер получает только текст + локаль, не каталог.

Результат: QueryIntent → terms, tags, language, country_code

  • Ошибка парсера → автоматический fallback на детерминированный парсер
  • Невалидные фильтры (напр. language="english") → тоже fallback

3. Генерация эмбеддинга запроса (EmbeddingProvider)

Опционально: onnx-e5-local (384-dim E5) или deterministic-dev.

Если провайдер недоступен → поиск только по метаданным, без semantic score.

4. SQL-запрос в PostgreSQL (SEARCH_SQL)

Параметры из домена:

  • $1 terms[], $2 tags[] — для metadata score
  • $3 language, $4 country_code — жёсткие фильтры
  • $5 excluded_station_ids[] — исключения
  • $6 limit
  • $7 query embedding vector, $8–$10 model/version/dimension
  • $11 metadata_weight=0.70, $12 semantic_weight=0.30

5. CTE «candidates» — фильтрация

  • WHERE: language = $3, country_code = $4, NOT id IN excluded
  • JOIN LATERAL: первый поток (is_primary DESC, id ASC)
  • LEFT JOIN station_embeddings: только совпадающий model+version+dimension
  • Подсчёт matched_count: совпадение term-в из name/tags + точное совпадение tag-ов

6. CTE «scored» — скоринг

metadata_score = matched_count / max(len(terms) + len(tags), 1)

semantic_score = clamp(0…1, 1 − cosine_distance / 2)

7. Финальный SELECT — гибридный ранг

score = 0.70 × metadata + 0.30 × semantic
Если semantic_score IS NULL → score = metadata_score (полный вес метаданных)

8. Сортировка и обрезка

ORDER BY score DESC, id ASC — стабильный tie-break по station ID

LIMIT $6

WHERE metadata_score > 0 OR semantic_score > 0 — нулевые не возвращаются

9. Пост-фильтрация в Rust (SearchService)

  • score ≥ MIN_RELEVANCE_SCORE (0.35)
  • Проверка совпадения жанра: если запрос содержит теги, хотя бы один должен совпадать

10. HTTP-ответ

Массив RankedStation с полями station + score + reason

SEARCH_SQL — полный текст с комментариями

-- CTE 1: кандидаты после жёстких фильтров WITH candidates AS ( SELECT s.id, s.name, primary_stream.stream_url, s.homepage_url, s.tags, s.language, s.country_code, primary_stream.codec, primary_stream.bitrate_kbps, primary_stream.health, station_embedding.embedding, -- Metadata match: сколько query-термов нашлось в name+tags ( SELECT COUNT(DISTINCT query_term.term) FROM UNNEST($1::text[]) AS query_term(term) WHERE EXISTS ( SELECT 1 FROM ( -- токены из имени станции SELECT token FROM regexp_split_to_table(lower(s.name), '[^[:alnum:]]+') AS token UNION -- токены из тегов SELECT token FROM UNNEST(s.tags) AS tag CROSS JOIN LATERAL regexp_split_to_table(lower(tag), '[^[:alnum:]]+') AS token ) AS searchable_terms WHERE token <> '' AND token = query_term.term ) ) + ( -- Точное совпадение тегов целиком SELECT COUNT(DISTINCT query_tag.tag) FROM UNNEST($2::text[]) AS query_tag(tag) WHERE query_tag.tag = ANY(s.tags) ) AS matched_count FROM stations AS s -- Первый (primary) поток станции JOIN LATERAL ( SELECT stream_url, codec, bitrate_kbps, health FROM station_streams WHERE station_id = s.id ORDER BY is_primary DESC, id ASC LIMIT 1 ) AS primary_stream ON true -- Embedding только если совпадает model+version+dimension И вектор запроса не NULL LEFT JOIN station_embeddings AS station_embedding ON station_embedding.station_id = s.id AND station_embedding.model = $8 AND station_embedding.version = $9 AND station_embedding.dimension = $10 AND $7::text IS NOT NULL -- Жёсткие фильтры WHERE ($3::text IS NULL OR s.language = $3) AND ($4::text IS NULL OR s.country_code = $4) AND NOT (s.id = ANY($5::text[])) ), -- CTE 2: скоринг scored AS ( SELECT *, matched_count::float8 / GREATEST(cardinality($1::text[]) + cardinality($2::text[]), 1) AS metadata_score, CASE WHEN embedding IS NULL OR $7::text IS NULL THEN NULL ELSE LEAST(1.0, GREATEST(0.0, 1.0 - (embedding <=> ($7::text)::vector) / 2.0)) END AS semantic_score FROM candidates ) -- Финальный выбор с гибридным ранжированием SELECT id, name, stream_url, homepage_url, tags, language, country_code, codec, bitrate_kbps, health, metadata_score, semantic_score, CASE WHEN semantic_score IS NULL THEN metadata_score ELSE $11::float8 * metadata_score + $12::float8 * semantic_score END AS score FROM scored WHERE metadata_score > 0 OR semantic_score > 0 ORDER BY score DESC, id ASC LIMIT $6
Параметры:
$1 = terms[]   $2 = tags[]   $3 = language   $4 = country_code
$5 = excluded_ids[]   $6 = limit   $7 = query_embedding_vector
$8 = model   $9 = version   $10 = dimension
$11 = METADATA_WEIGHT (0.70)   $12 = SEMANTIC_WEIGHT (0.30)

Backfill эмбеддингов (отдельный CLI)

cargo run --features onnx-local --bin backfill_embeddings

Запускается вне HTTP-сервера. Не вызывается при старте или поиске.

1. Чтение документов постранично

SELECT id, searchable_text FROM stations ORDER BY id ASC

searchable_text = name + tags + language + country_code (конкатенация через пробел)

2. Генерация эмбеддинга для каждой станции

EmbeddingProvider.embed_document(text) → Embedding(model, version, dimension, vector)

Для E5: текст оборачивается в "passage: {text}"

3. Upsert в station_embeddings

INSERT ... ON CONFLICT (station_id, model, version) DO UPDATE

Идемпотентно: повторный запуск обновляет существующие строки

Результат

Каждая станция получает строку в station_embeddings с:
model=intfloat/multilingual-e5-small, version=onnx-v1, dimension=384

Импорт Radio Browser (отдельный CLI)

cargo run --bin import_radio_browser

Отдельный от HTTP-сервера процесс.

1. Создание import_run (status=started)

Записывает UUID, source=radio_browser, started_at

2. Постраничная загрузка с Radio Browser API

Пагинация по offset, сортировка по stationuuid.
Ограничения: max 500 на страницу, max 100 страниц, 8 MiB на ответ.

3. Валидация и нормализация каждой записи

  • lastcheckok=1, непустой UUID и name, валидный HTTP(S) stream URL
  • Теги: lowercase, сортировка, дедупликация
  • Язык: первый валидный 2-буквенный код; fallback на 3-буквенный
  • Страна: валидный alpha-2
  • Битрейт: 1–2000 kbps

4. Upsert в stations и station_streams

Ключ: (source='radio_browser', source_station_id=stationuuid)

Существующие 6 builtin-станций не затрагиваются (другой source)

5. Финализация import_run

status → completed/failed, счётчики: fetched, imported, skipped, failed
