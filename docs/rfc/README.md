# RFC

Предложения по изменениям, которые ещё не приняты к реализации. RFC фиксирует идею, обоснование, цену и критерии
решения; принятый RFC превращается в этап ТЗ или задачу в `docs/tasks.md`.

Интерфейс сервисов — `rock-llm-service/docs/contract.md`; ссылки RFC «ТЗ 6.x» — на ТЗ потребителей `roadmap/ai-provider-architecture.md`.

Статусы: **Proposed** (предложено) → **Accepted** / **Rejected** / **Superseded**.

**Правило текущей версии программы: только CPU, без разделения на тарифы.** Всё, что требует GPU, оформляется
RFC на следующую версию.
