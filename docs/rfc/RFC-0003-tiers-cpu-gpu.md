# RFC-0003: тарифы — бесплатный (CPU) и платный (GPU)

- Статус: **Proposed** — для **следующей версии программы**
- Дата: 2026-10-11
- Автор: Claude (лид), по решению владельца: «для бесплатных пользователей — версия на CPU, для платных — на GPU;
  в текущей версии разделения нет»
- Связано: RFC-0001, RFC-0002, RFC-0004; ТЗ `docs/roadmap/ai-provider-architecture.md`

## Контекст

Текущая версия работает только на CPU и без тарифов. В следующей версии пользователи делятся на бесплатных (CPU) и
платных (GPU). Возможности, требующие GPU (RFC-0001, RFC-0002, RFC-0004), становятся платными.

## Что нужно решить (открытые вопросы владельцу)

1. **Эмбеддинги**: у тарифов разные модели (бесплатный — `e5-small` на CPU, платный — BGE-M3 на GPU) или одна модель на
   разном железе? Разные модели → две постоянно заполняемые таблицы векторов и выбор таблицы по тарифу (пересмотр
   принципа ТЗ «один эмбеддер»). Одна модель → одна таблица, тарифы различаются только скоростью; но BGE-M3 на CPU не
   укладывается в бюджет, значит общей моделью может быть только лёгкая.
2. **STT и LLM**: тариф влияет на выбор провайдеров? Если да — разделы `stt`/`llm` файла провайдеров языка задаются по
   тарифам (основной и запасной для каждого).
3. Переранжирование (RFC-0002) — только для платного тарифа?

## Предлагаемая схема

- **Тариф — вход маршрутизации**, как язык общения: определяется в `rockserver` из аккаунта (подписка); анонимный
  пользователь — бесплатный. Тариф передаётся в сервисы модулей вместе с языком.
- Возможности по тарифу задаются **конфигурацией** (таблица «тариф → набор возможностей»), а не кодом: версия
  эмбеддера, включено ли переранжирование, файл провайдеров языка.
- Лимиты запросов (ТЗ 6.10) — по тарифу.
- Деградация: GPU-сервис недоступен → платный пользователь обслуживается по схеме бесплатного (CPU), без ошибки.
- Метрики — с меткой тарифа.

## Как решаем

Принимаем после ответов на открытые вопросы и согласования модели подписки (откуда `rockserver` узнаёт тариф).

## Когда

Следующая версия программы, вместе с появлением GPU.
