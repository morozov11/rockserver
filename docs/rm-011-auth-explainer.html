RM-011: регистрация без геморроя

Человек подтверждает себя через passkey в браузере. RockCast и RockMobile получают отдельную привязанную сессию — без ручного ввода токенов, без пароля в приложении и без остановки радио, если сервер временно недоступен.

2. Как пользователь создаёт аккаунт или входит

Важно: passkey не является паролем, который надо где-то хранить. Его проверяет ОС/браузер. Браузер получает только защищённую cookie-сессию; нативные токены RockCast/RockMobile ему не выдаются.

3. Как ПК или приложение привязываются к аккаунту

Приложение не передаёт user_id для завершения привязки. Сервер сам берёт владельца из уже одобренного pairing request — подменить чужого пользователя нельзя.

4. Где что хранится — и где точно не хранится

Браузер телефона

Есть: защищённая cookie-сессия для сайта и подтверждения pairing.

Нет: native access/refresh токенов.

RockCast / RockMobile

Есть: access token и rotating refresh token после одобрения.

Windows: DPAPI. Android: Android Keystore + encrypted private storage.

RockServer + PostgreSQL

Есть: состояние pairing, пользователи, устройства, хэши секретов, аудит.

Нет: plaintext токенов в логах или конфигурации.

5. Что если сервер упал?

Радио не ломается

Анонимный режим и базовое воспроизведение остаются рабочими. RockServer добавляет аккаунтные и AI-возможности, но не является обязательным для радио.

Когда сервер вернулся

Клиент может обновить сессию через refresh token. Если устройство отозвано или сессия истекла — клиент спокойно возвращается в anonymous mode.

Пользователь управляет доступом

Можно увидеть устройства, отозвать лишнее, выйти из клиента. Лимит — до 10 устройств на аккаунт; аудит хранится 90 дней.

Один живой сценарий

  1. В RockCast или RockMobile нажать «Подключить аккаунт».
  2. Открыть QR-ссылку на телефоне и создать/подтвердить passkey.
  3. Сверить код или phrase и одобрить устройство.
  4. Приложение само переходит в статус «Подключено»; вручную токен вводить не надо.
  5. После перезапуска сессия восстанавливается. Logout или revoke устройства снова переводит клиента в анонимный режим.
